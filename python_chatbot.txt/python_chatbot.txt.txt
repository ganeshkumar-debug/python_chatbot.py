## SECTION 1: BASICS

Q: What is Python?
A: Python is a high-level, interpreted, general-purpose programming language known for its simple, readable syntax. It is used for web development, data science, automation, AI, and more.

Q: Who created Python?
A: Python was created by Guido van Rossum and first released in 1991.

Q: Is Python free?
A: Yes. Python is open source and free to download and use, including for commercial projects.

Q: Is Python compiled or interpreted?
A: Python is mainly interpreted. Source code is compiled to bytecode, which the Python Virtual Machine then executes.

Q: Is Python case-sensitive?
A: Yes. "name" and "Name" are two different variables.

Q: How do I install Python?
A: Download the installer from python.org, run it, and tick "Add Python to PATH". Verify with: python --version

Q: How do I run a Python file?
A: Open a terminal and type: python filename.py (or python3 filename.py on Mac/Linux).

Q: How do I print text in Python?
A: Use the print() function. Example: print("Hello, World!")

Q: How do I write comments in Python?
A: Use # for single-line comments. For multi-line notes, use triple quotes """ ... """ (docstrings).

Q: Why does Python use indentation?
A: Indentation defines code blocks (like inside if, for, functions). It replaces curly braces and makes code readable. Use 4 spaces per level.

## SECTION 2: VARIABLES AND DATA TYPES

Q: How do I create a variable?
A: Just assign a value: x = 10, name = "Ali". No type declaration is needed.

Q: What are the main data types in Python?
A: int, float, str, bool, list, tuple, dict, set, and NoneType.

Q: How do I check the type of a variable?
A: Use type(). Example: type(5) returns <class 'int'>.

Q: How do I convert between types?
A: Use int(), float(), str(), list(), etc. Example: int("5") gives 5.

Q: What is None?
A: None represents "no value". It is the only value of type NoneType.

Q: What are the rules for variable names?
A: They must start with a letter or underscore, contain only letters, digits, and underscores, and cannot be a reserved keyword.

Q: How do I take user input?
A: Use input(). Example: name = input("Your name: "). The result is always a string.

Q: How do I format strings?
A: Use f-strings: f"Hello {name}, you are {age}". You can also use .format() or % formatting.

## SECTION 3: OPERATORS

Q: What are the arithmetic operators?
A: + (add), - (subtract), * (multiply), / (divide), // (floor divide), % (modulus), ** (power).

Q: What is the difference between / and //?
A: / returns a float (7/2 = 3.5). // returns the floor integer (7//2 = 3).

Q: What is the difference between == and is?
A: == compares values. "is" checks whether two names refer to the same object in memory.

Q: What are logical operators?
A: and, or, not.

Q: What does the in operator do?
A: It checks membership. Example: 3 in [1, 2, 3] returns True.

## SECTION 4: CONTROL FLOW

Q: How do I write an if statement?
A: if x > 5:
       print("big")
   elif x == 5:
       print("five")
   else:
       print("small")

Q: How does a for loop work?
A: It iterates over a sequence. Example: for i in range(5): print(i) prints 0 to 4.

Q: How does a while loop work?
A: It repeats while a condition is True. Example: while x < 10: x += 1

Q: What do break and continue do?
A: break exits the loop immediately. continue skips to the next iteration.

Q: What does pass do?
A: pass is a placeholder that does nothing. It is used where code is syntactically required but not yet written.

Q: What does range() do?
A: It generates a sequence of numbers. range(start, stop, step). Example: range(1, 10, 2) gives 1, 3, 5, 7, 9.

Q: What is the match statement?
A: Introduced in Python 3.10, match/case is structural pattern matching, similar to switch statements in other languages.

## SECTION 5: DATA STRUCTURES

Q: What is a list?
A: An ordered, mutable collection. Example: fruits = ["apple", "banana"]. Use append(), remove(), pop(), sort().

Q: What is a tuple?
A: An ordered, immutable collection. Example: point = (3, 4). It cannot be changed after creation.

Q: What is a dictionary?
A: A collection of key-value pairs. Example: person = {"name": "Ali", "age": 20}. Access with person["name"].

Q: What is a set?
A: An unordered collection of unique items. Example: s = {1, 2, 3}. Useful for removing duplicates.

Q: What is the difference between a list and a tuple?
A: Lists are mutable (changeable) and use []; tuples are immutable and use (). Tuples are slightly faster and can be dictionary keys.

Q: How do I add an item to a list?
A: Use append() for one item at the end, insert(index, item) for a position, or extend() to add many.

Q: How do I remove duplicates from a list?
A: Convert to a set and back: list(set(my_list)). To keep order: list(dict.fromkeys(my_list)).

Q: How do I sort a list?
A: Use my_list.sort() to sort in place, or sorted(my_list) to return a new list. Add reverse=True for descending.

Q: How do I get the length of a list or string?
A: Use len(). Example: len([1, 2, 3]) returns 3.

Q: What is slicing?
A: Extracting part of a sequence: my_list[start:stop:step]. Example: [1,2,3,4,5][1:4] gives [2, 3, 4].

Q: How do I loop through a dictionary?
A: for key, value in my_dict.items(): print(key, value)

Q: What is a list comprehension?
A: A short way to build lists. Example: squares = [x**2 for x in range(5)] gives [0, 1, 4, 9, 16].

## SECTION 6: STRINGS

Q: How do I make a string uppercase or lowercase?
A: Use .upper() and .lower(). Example: "hi".upper() returns "HI".

Q: How do I split and join strings?
A: "a,b,c".split(",") gives ["a","b","c"]. ",".join(["a","b","c"]) gives "a,b,c".

Q: How do I remove whitespace from a string?
A: Use .strip() (both ends), .lstrip() (left), .rstrip() (right).

Q: How do I replace text in a string?
A: Use .replace(old, new). Example: "hello".replace("l", "x") gives "hexxo".

Q: Are strings mutable?
A: No. Strings are immutable; string methods return a new string.

Q: How do I check if a string contains another string?
A: Use the in operator: "py" in "python" returns True.

## SECTION 7: FUNCTIONS

Q: How do I define a function?
A: def greet(name):
       return "Hello " + name

Q: What is the difference between print and return?
A: print displays a value on screen. return sends a value back to the caller so it can be stored or used.

Q: What are default arguments?
A: Parameters with preset values: def greet(name="friend"). They are used if no argument is passed.

Q: What are *args and **kwargs?
A: *args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dictionary.

Q: What is a lambda function?
A: A small anonymous function written in one line. Example: add = lambda a, b: a + b.

Q: What is recursion?
A: When a function calls itself. It needs a base case to stop. Example: factorial(n) = n * factorial(n-1).

Q: What is a decorator?
A: A function that wraps another function to extend its behavior without changing its code. It is applied with the @ symbol.

Q: What is a generator?
A: A function that uses yield to produce values one at a time, saving memory. Example: def count(): yield 1; yield 2.

Q: What is variable scope?
A: Scope defines where a variable is accessible. Python follows LEGB: Local, Enclosing, Global, Built-in.

Q: What do global and nonlocal do?
A: global lets a function modify a module-level variable. nonlocal modifies a variable in an enclosing function.

## SECTION 8: OBJECT-ORIENTED PROGRAMMING

Q: What is a class?
A: A blueprint for creating objects. Example: class Dog: pass.

Q: What is an object?
A: An instance of a class. Example: d = Dog().

Q: What is __init__?
A: The constructor method, called automatically when an object is created. It sets up initial attributes.

Q: What is self?
A: A reference to the current instance of the class. It is the first parameter of instance methods.

Q: What is inheritance?
A: A class can inherit attributes and methods from a parent class: class Puppy(Dog).

Q: What is polymorphism?
A: Different classes can have methods with the same name that behave differently.

Q: What is encapsulation?
A: Bundling data and methods together and restricting direct access. Python uses a leading underscore (_name) by convention for private members.

Q: What is the difference between a class method and a static method?
A: A classmethod (@classmethod) receives the class (cls) as its first argument. A staticmethod (@staticmethod) receives neither self nor cls.

Q: What are dunder (magic) methods?
A: Special methods with double underscores, like __init__, __str__, __len__, __add__. They customize object behavior.

## SECTION 9: ERRORS AND FILES

Q: How do I handle errors?
A: Use try/except:
   try:
       x = 1 / 0
   except ZeroDivisionError:
       print("Cannot divide by zero")

Q: What do finally and else do in try/except?
A: finally always runs, whether or not an error happened. else runs only if no error occurred.

Q: How do I raise an error?
A: Use raise. Example: raise ValueError("Invalid value").

Q: How do I read a file?
A: with open("file.txt", "r") as f:
       content = f.read()

Q: How do I write to a file?
A: with open("file.txt", "w") as f:
       f.write("Hello")
   Use "a" to append instead of overwrite.

Q: Why use "with" when opening files?
A: It automatically closes the file, even if an error occurs.

Q: What is a SyntaxError?
A: An error raised when Python cannot parse your code, such as a missing colon or bracket.

Q: What is an IndentationError?
A: An error caused by inconsistent or missing indentation.

Q: What is a NameError?
A: It occurs when you use a variable or function name that has not been defined.

Q: What is a TypeError?
A: It occurs when an operation is applied to the wrong type, like "5" + 5.

## SECTION 10: MODULES AND PACKAGES

Q: What is a module?
A: A .py file containing Python code (functions, classes, variables) that you can import.

Q: How do I import a module?
A: import math, or from math import sqrt, or import numpy as np.

Q: What is pip?
A: Python's package installer. Example: pip install requests.

Q: What is a virtual environment?
A: An isolated environment with its own packages for a project. Create with: python -m venv venv

Q: What is the standard library?
A: The collection of built-in modules shipped with Python, such as os, sys, math, random, datetime, json, and re.

Q: What does if __name__ == "__main__" mean?
A: It runs code only when the file is executed directly, not when it is imported as a module.

Q: How do I work with JSON?
A: Use the json module: json.loads(text) parses a string; json.dumps(obj) converts to a string; json.load / json.dump work with files.

Q: How do I generate a random number?
A: import random; random.randint(1, 10) returns a random integer from 1 to 10.

Q: How do I get the current date and time?
A: from datetime import datetime; datetime.now()

## SECTION 12: ADVANCED TOPICS

Q: What is the GIL?
A: The Global Interpreter Lock lets only one thread execute Python bytecode at a time in CPython. Use multiprocessing for CPU-bound parallelism.

Q: What is the difference between threading and multiprocessing?
A: Threading runs threads in one process (good for I/O tasks). Multiprocessing uses separate processes (good for CPU-heavy tasks).

Q: What is asyncio?
A: A library for asynchronous programming using async/await, ideal for many concurrent I/O operations.

Q: What are type hints?
A: Optional annotations showing expected types. Example: def add(a: int, b: int) -> int. They help tools and readers but are not enforced at runtime.

Q: What is a context manager?
A: An object that defines setup and cleanup using "with". It implements __enter__ and __exit__.

Q: What is the difference between deep copy and shallow copy?
A: A shallow copy copies the outer object but shares nested objects. A deep copy (copy.deepcopy) copies everything recursively.

Q: What is a mutable default argument problem?
A: Using a list or dict as a default argument (def f(x=[])) shares the same object across calls. Use None and create the list inside the function instead.

Q: How does Python manage memory?
A: It uses automatic memory management with reference counting plus a garbage collector for cycles.

Q: What is PEP 8?
A: The official Python style guide covering naming, indentation, line length, and more.

Q: What is the Zen of Python?
A: A set of guiding principles for Python design. View it by running: import this
